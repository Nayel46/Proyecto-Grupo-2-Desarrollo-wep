# Sistema Web para la Gestión de Citas Médicas

Sistema web desarrollado para facilitar la gestión de citas médicas en un consultorio privado, centralizando la información de pacientes, médicos, especialidades, horarios y citas en una sola plataforma.

## Descripción

El sistema permite administrar de forma organizada las citas médicas y la información relacionada con pacientes y médicos. Los pacientes pueden consultar médicos y horarios disponibles, solicitar citas, cancelarlas o reprogramarlas, mientras que el personal del consultorio puede administrar la información general del sistema.

## Tipos de usuarios

- **Administrador:** Gestiona pacientes, médicos, especialidades, horarios, citas y usuarios.
- **Médico:** Consulta sus citas programadas y la información relacionada con sus pacientes.
- **Paciente:** Se registra, consulta médicos y horarios disponibles, solicita citas, cancela o reprograma citas y consulta su historial.

## Funcionalidades principales

- Registro y administración de pacientes.
- Registro y administración de médicos.
- Gestión de especialidades.
- Administración de horarios disponibles.
- Solicitud de citas médicas.
- Consulta, cancelación y reprogramación de citas.
- Control del estado de las citas.
- Consulta del historial de citas.
- Autenticación y control de acceso según el tipo de usuario.
- Operaciones CRUD.
- Almacenamiento de información en MySQL.

## Tecnologías utilizadas

- Java
- Spring Boot
- Spring MVC
- Thymeleaf
- Bootstrap
- Hibernate / JPA
- MySQL

## Objetivo

Desarrollar una plataforma que permita centralizar y mejorar la administración de las citas médicas, reduciendo la gestión manual y facilitando el acceso a la información tanto para el personal del consultorio como para los pacientes.

## Proyecto académico

Este proyecto fue desarrollado como parte del proceso académico, aplicando conceptos de desarrollo web, arquitectura MVC, bases de datos, operaciones CRUD, persistencia con JPA/Hibernate y gestión de usuarios.
